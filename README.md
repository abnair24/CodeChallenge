## Build & Run

Requirements: **JDK 21** and **Maven**.

```bash
# Compile everything
mvn clean compile

# Run the test suite (TestNG)
mvn test
```

Each problem lives in its own class; open a folder above and run the `main` method (or the associated test) for the problem you want.

## Keeping the index current

The topic tables between the `INDEX` markers are generated, not hand-maintained. After adding or removing problems, regenerate them:

```bash
./scripts/gen-readme-index.sh
```

The script only **reads** the source tree and rewrites the marker block — it never moves, renames, or deletes any files.
